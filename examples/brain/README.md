# Synthetic example brain

This directory is a tiny, valid Engramkeep store. It contains only synthetic
data and is safe to commit.

Try it:

```bash
engramkeep --home examples/brain search sqlite
engramkeep --home examples/brain show example-project
engramkeep --home examples/brain doctor
```

Do not copy real memory into this directory. Use your own `ENGRAMKEEP_HOME`
or the platform default for real data.
